# Train Pack Compatibility Matrix

This matrix tracks external train/resource-pack compatibility for Immersive Railroading Reforged. Do not mark a pack as working unless it has been tested on the listed port version with enough evidence to reproduce the result.

Status values:

- `unknown`: not tested yet
- `works`: loads and behaves correctly for the tested scope
- `partial`: some content loads, but issues remain
- `broken`: tested and does not currently work
- `blocked by license`: compatibility cannot be validated or redistributed because permission is unclear or denied

## Review Rules

- Link to the original source instead of copying pack assets into this repository.
- Record the license and permission status before testing or publishing compatibility claims.
- Keep notes specific: what loaded, what failed, missing assets, log excerpts, and screenshots where useful.
- Treat compatibility as pack-specific, not as a blanket guarantee for all original IR packs.
