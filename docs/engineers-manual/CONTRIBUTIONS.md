# Engineer Manual Contributions

Current first-party implementation scope:

- Resource-only IR-owned content under `assets/immersiverailroading/engineers_manual`.

Future contribution model:

- Resource-only contributions from other namespaces.
- Optional programmatic providers for dynamic entries.
- Mod-loaded conditions for optional integrations.
- Config/capability conditions for generated references.

Excluded by user instruction:

- TrackAPI technical-reference contribution examples.
- Universal Mod Core technical-reference contribution examples.

Integration examples should be added only for integrations actually present in the checked-out source and guarded by a mod-loaded condition.
